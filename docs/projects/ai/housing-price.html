Machine Learning
Regression
Published

Description

This is the second practical assignment for the Data Science course (2023) in the Department of Mathematics, Universitas Indonesia.

The objective of this practical assignment is to perform an end-to-end machine learning process (regression model)—encompassing data cleaning, data transformation, EDA, and modeling—to predict house prices based on the provided data.
